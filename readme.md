# Private Forum – Django Project

## Setup
Create a **.env** file and place the following variables inside:
```bash
PAYPAL_MODE="sandbox"
PAYPAL_CLIENT_SECRET=""
PAYPAL_CLIENT_ID=""
```
![register](img/vs_code/env.png)
```
pip install -r requirements.txt
python manage.py migrate
```

## Admin Panel
If the user is a **head moderator**, they can see everything shown in the images.  
If the user is only a **moderator**, they **cannot generate keys**.
![admin_view](img/admin/admin_view.png)
### Check Sell Posts
![sell_post_view](img/admin/sell_post_view.png)

When selecting a product, moderators can **approve** or **delete** it:

![approve_post](img/admin/approve_post.png)
### Post

When you click on **Check Post**, you will see the post details.  
![normal post](img/admin/post_view.png)
From here, you can either **delete the entire post** along with all its comments, or **delete a single comment**.
![delete comment](img/admin/comment.png)
### Generate Key

Head moderators also have access to **key generation**:

![gen key admin](img/admin/genkeys.png)
